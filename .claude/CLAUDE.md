## ソースコード中のコメント

ソースコード中のコメントは次のことを意識して書いて。

* コードの目的、意図を明確にする
* コードを読むだけでは後から得ることが出来ない情報を書く
* 処理の内容を単に自然言語で書き下したコメントは書かない。そのようなコメントを書くぐらいならば、コメントはない方が良い。

## Git の扱い

コードに何かしら変更を加えた場合、最後にgit commitをして。1回の命令内に複数の指示が含まれている場合、1つの指示ごとにコミットを分けて。
コミットメッセージは英語で書いて。コミットメッセージの1行目にはそのコミットの概要を簡潔にまとめて。2行目以降には実装の詳細を書いて。
git add と git commit は`&&`で繋げず、2回のコマンド実行に分けて。
